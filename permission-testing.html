Permission Testing

Test how the WebView handles browser permission requests

About This Page

Each card below invokes a browser API that triggers a permission prompt. Use this to verify that the WebView correctly surfaces, grants, denies, and persists these permission flows. Some APIs require a secure context (HTTPS/localhost) and a user gesture.

🌎

Geolocation

navigator.geolocation

Requests the device's current geographic location.

📷

Camera

getUserMedia({ video: true })

Requests access to the device camera.

🎤

Microphone

getUserMedia({ audio: true })

Requests access to the device microphone.

🎥

Camera + Microphone

getUserMedia({ video: true, audio: true })

Requests simultaneous camera and microphone access.

🔔

Notifications

Notification.requestPermission()

Requests permission to send push notifications.

📋

Clipboard Read

navigator.clipboard.readText()

Requests permission to read text from the system clipboard.

📝

Clipboard Write

navigator.clipboard.writeText()

Requests permission to write text to the system clipboard.

🔍

Query All Permissions

navigator.permissions.query()

Query the current state of all knowable permissions without triggering prompts.
